# Yet-Another-Rotary-GPT

## English description
Yet-Another-Rotary-GPT is a GPT-style transformer model comparable in size to GPT‑2, trained from scratch with rotary positional embeddings. This repository contains the full training pipeline, configuration files, and scripts for reproducing experiments and extending the model for research or custom datasets.

## Описание по‑русски
Yet-Another-Rotary-GPT — это трансформер в стиле GPT, сопоставимый по размеру с GPT‑2 и обученный с нуля с использованием rotary positional embeddings. В репозитории представлены полный тренировочный пайплайн, конфигурационные файлы и скрипты для воспроизведения экспериментов и дальнейшего расширения модели под исследовательские задачи или собственные датасеты.
